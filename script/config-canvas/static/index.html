How to read the atlas

hoverOpen the dossier: size, lines, mode, owner, modified time, preview.
drag nodePull a node. Springs in the lines tug its parents and neighbours.
right dragPan the endless canvas from anywhere — never drags a node.
wheelZoom around the pointer. Coordinates are unbounded.
FFit everything back into view.
ARandomly rearrange the constellation.
/Find a node by name or path. Enter jumps to the first hit.
LLink mode. Click two nodes to draw a dashed freeform thread.
double-clickFold a content node, or remove one of your dashed links.
1 / 2Files view / content-structure view.
RRescan the folder and rebuild the atlas.
?This card.
escCancel link mode or close panels.

Each folder has its own muted tint. Root files hang directly from the big root folder node. Lines are containment in the files view and expression structure in content view. Every run rescans the folder, so edits show up on SCAN or reload.
